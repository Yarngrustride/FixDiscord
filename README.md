> [!WARNING]

> ### СРАБАТЫВАНИЕ АНТИВИРУСА
>
> Для работы zapret требуется WinDivert, поэтому антивирус может отреагировать на его файлы.  
> WinDivert перехватывает и фильтрует сетевой трафик.
> Этот инструмент могут применять как легитимные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл может быть удалён и отправлен в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенном понимании настроек предпочтительно создать исключение, а если вы не уверены в своих действиях - отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется использовать этот способ
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив со [страницы последнего релиза](https://github.com/Yarngrustride/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите пункт "Разблокировать". При распаковке через 7-Zip или PeaZip этот шаг не требуется

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы определить рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для запуска стратегии вместе с системой выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вашей системы**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - смена режима обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние включено/выключено отображается в скобках.
  - **`IPSet Filter`** - изменение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт может пригодиться при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках показывается один из статусов:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - адреса проверяются на наличие в списке
    - `any` - под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** - включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** - ручная проверка новой версии
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В завершение доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного сбоя
  - **`Run Tests`** - проверка стратегий:
    - `Standard tests` - проверяет сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe, отвечающий за обход.  
Если процесса нет, обратитесь к [#522](https://github.com/Yarngrustride/zapret-discord-youtube/issues/522)

### Рабочая стратегия не находится
- Запустите командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открывшегося блокнота
  - В созданной папке найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените им ранее добавленные аналогичные записи
  - Сохраните файл и снова проверьте соединение. Если проблема останется, убедитесь, что изменения действительно записались.

#### Совместимость не гарантируется. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Yarngrustride/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут устаревать и переставать работать.**
> Даже рабочий вариант со временем может быть обнаружен и потерять эффективность.
> Здесь собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте наличие ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/Yarngrustride/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Запустите `service.bat` -> `Remove Services`
- Выберите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце подтвердите `Y`
- Удалите старый каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/Yarngrustride/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если в нижней части окна есть флажок разблокировки, включите его, нажмите применить и затем ОК
- Распакуйте архив в новую папку в корне диска, исключив пробелы, специальные символы и кириллицу
- Запускайте разные скрипты `general`, проверяя доступность нужных ресурсов. Если очередной вариант не работает, закройте программу через иконку замка в панели задач и выберите другую стратегию
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение перестало работать при активном zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится в службах

1. Определите имя службы командой в командной строке Windows, которую можно открыть через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fустановка-и-запуск)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fустановка-и-запуск)
- Сначала желательно выяснить, какая стратегия открывает YouTube, и запустить именно её
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте, начал ли работать клиент Discord после очистки
- Откройте Discord через браузер: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею
- Если сайт также недоступен, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/Yarngrustride/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно помогает следующий порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить доступ к большому числу сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если это не решило проблему, создайте обсуждение в разделе [Discussions](https://github.com/Yarngrustride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

- Опишите проблему [здесь](https://github.com/Yarngrustride/zapret-discord-youtube/issues)

## 🗒️Добавление других адресов

Перечень ресурсов для обхода можно расширить в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть указана в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
